TAKTO / Изображения для лендинга

Откройте index.html в браузере для просмотра 24 изображений.
01–12: категории продукции.
13–22: образцы материалов и эффектов.
23: веер специальных материалов.
24: общая композиция для первого экрана.
icons/: 12 масштабируемых лаймовых SVG-иконок для услуг, преимуществ и кнопок.

PNG созданы встроенным imagegen по вашему референсу; промпты сохранены в Промпты.txt.
Это заново сгенерированные визуальные концепты, а не фотографии реально изготовленных заказов. Изображения иллюстрируют материал и стиль, но не доказывают его технические характеристики.
Фон изображений тёмно-синий; он не прозрачный. Текстовые заголовки, списки и кнопки накладывайте средствами HTML/CSS.
Файлы можно использовать независимо. Для веба рекомендуется делать оптимизированные копии WebP/AVIF с сохранением оригиналов PNG.
Главный HTML лендинга этим набором автоматически не заменяется.
